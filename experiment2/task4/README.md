# 任务 4 定性与定量评价

任务 1 为 DIV2K 生成两种高斯核尺寸与三种边界方式的六组退化图，并提供 RealBlur-J 的配对灰度图。任务 2 负责频域复原，任务 3 提供双三次插值与 NLM 对照。每个分支均以配对的清晰图像作为 GT。

## 评价口径与图表

频域复原复用任务 2 的实现。DIV2K 读取任务 1 保存的已知 PSF。RealBlur-J 在真实核未知的条件下测试四个假设高斯核。所有同尺寸结果按 `data_range=1.0` 计算 PSNR 和 SSIM，频域结果以裁剪至 `[0,1]` 的浮点图像直接计算。Bicubic 与 NLM 复用任务 3 的 8 位灰度处理，评价时按 `/255` 归一化。直接 2 倍插值用于视觉观察。表中的 Bicubic 是先以 `INTER_AREA` 缩小至一半，再以 `INTER_CUBIC` 恢复为原尺寸的 Down-Up 对照。

## DIV2K 结果

高斯 PSF 的标准差固定为 `σ=3`，六组退化共用一次采样的 `σₙ=0.01` 高斯噪声。每种核尺寸在三种边界模式下使用同一组复原参数。表中每格为 **PSNR（dB）/ SSIM**。

### 15×15

|---|---:|---:|---:|
| LQ | 24.60 / 0.641 | 24.86 / 0.643 | 24.75 / 0.642 |
| 全逆滤波 | 5.16 / 0.003 | 5.16 / 0.003 | 5.16 / 0.003 |
| 受限逆滤波 `D0=150` | 24.92 / 0.678 | 25.24 / 0.676 | 25.71 / 0.698 |
| Wiener `K=0.01` | 26.14 / 0.778 | 26.86 / 0.779 | 27.35 / **0.786** |

### 19×19

| 方法 | 零填充 | 反射延拓 | 周期延拓 |
|---|---:|---:|---:|
| LQ | 24.52 / 0.637 | 24.78 / 0.639 | 24.66 / 0.638 |
| 全逆滤波 | 5.30 / 0.004 | 5.30 / 0.004 | 5.30 / 0.004 |

| Bicubic Down-Up | 24.60 / 0.655 | 24.85 / 0.657 | 24.74 / 0.656 |

- **轮廓与纹理。** 在企鹅轮廓的局部图里，LQ 的边缘发糊，全逆滤波出现密集黑白噪点。Wiener 和 CLS 都能改善边缘清晰度，细羽毛及岩石纹理与 GT 仍有差异。反射模式下，两种核的 Wiener 都约为 26.86 dB，CLS 为 26.39–26.42 dB，核尺寸变化在这组设置下影响很小。
- **边界影响。** 相比反射组，周期组的 Wiener 提高约 0.49–0.52 dB，CLS 提高约 1.25–1.27 dB。以 15×15 为例，Wiener 的边界带 PSNR 由 20.47 提升到 24.75 dB，内部 PSNR 均约 27.49 dB。周期退化与当前 FFT 复原隐含的循环卷积一致。零填充使退化图外沿变暗，Wiener 和 CLS 的边界带 PSNR 也最低。周期组内 CLS 的 PSNR 最高，Wiener 的 SSIM 最高。
- **受限逆滤波。** 表中列出各核尺寸下反射组 PSNR 最好的 `D0`。完整扫描中，15×15 的零填充和反射组在 `D0=150` 同时取得最高 PSNR 和 SSIM，周期组在 `D0=200` 同时最高。19×19 的零填充和周期组在 `D0=180` 同时最高，反射组的 PSNR 与 SSIM 分别在 `D0=140` 和 `D0=180` 最高。

## 对应任务 5 的结果解释

- **逆滤波与噪声。** 在模型 `G=HF+N` 下，理想逆滤波的噪声项是 `N/H`。当 `|H|` 很小，噪声会被放大。带小常数的全逆在本次 DIV2K 实验中仍只有约 5 dB，裁剪前约 96.5%–99.95% 的像素越界。受限逆滤波用截止半径控制保留范围，硬截止也会在强边缘附近产生振铃。
- **Wiener 与 CLS 的调节。** Wiener 的 `K` 近似噪声与信号功率谱之比。`K` 小时更接近逆滤波，容易放大噪声。过大的 `K` 会在抑制噪声时损失细节。CLS 用 `γ` 加权拉普拉斯平滑约束，过大的 `γ` 会使纹理和边缘变软。15×15 反射组的 Wiener 在 `K=0.01`、CLS 在 `γ=0.05` 取得各自扫描中的最高指标。[任务 2 参数扫描](../task2/README.md)
- **模型与核失配。** DIV2K 的已知核能描述图像内部的高斯退化，在周期组也与 FFT 的边界假设相合。RealBlur-J 的拖尾有方向性，真实模糊还可能随位置改变。假设高斯核的幅频响应和真实退化不匹配，反演会在错误的频率上增加增益，放大残差并在强边缘产生亮暗振铃。
- **复原与插值。** 频域复原根据 PSF 反演模型重估清晰图像。Bicubic 由邻域像素估计新采样位置的灰度，Down-Up 的小幅指标变化伴随额外重采样和平滑。NLM 通过相似图像块平均来抑制噪声。
