# Task3 Extra：基于 Radon 变换的运动模糊核估计与图像复原

## 1. 实验目标

本实验对应《案例二：退化图像复原》的选做加分任务：

**尝试利用 Radon 变换粗略估计运动模糊的角度和长度，构造运动模糊 PSF，再进行图像复原。**

在 Task 2 中，RealBlur-J 的真实 PSF 未知，因此采用人工指定的高斯 PSF 进行频域复原。本实验进一步尝试从模糊图像自身的频谱特征中估计运动模糊参数，生成具有方向性的运动 PSF，并结合 Wiener 滤波和约束最小二乘（CLS）滤波进行复原。

实验主要验证三个问题：

1. 能否从理想直线运动模糊图像中估计运动方向和长度。
2. 使用估计 PSF 能否有效复原合成运动模糊图像，以及与真实 PSF 复原结果存在多大差异。
3. 在 RealBlur-J 图像上，估计的运动 PSF 是否比 Task 2 人工假设的高斯 PSF 更适合进行复原。

## 2. 实验方法

### 2.1 频谱分析与运动方向估计

对于输入模糊图像，首先进行灰度化和归一化，截取中心区域进行频谱分析。

主要步骤如下：

1. 对图像中心区域施加 Hanning 窗，降低边界不连续对频谱的影响。
2. 计算二维傅里叶变换及其对数幅度谱。
3. 对频谱进行预处理，突出与运动模糊相关的暗条纹结构。
4. 使用 Radon 变换计算不同角度下的投影响应。
5. 根据投影响应确定条纹方向，并转换为图像中的运动模糊方向。

理想直线运动模糊通常会在频谱中产生具有方向性的暗条纹，因此可以利用 Radon 变换辅助估计运动方向。

### 2.2 运动长度估计

在确定运动方向后，程序进一步分析频谱中的暗纹位置，根据暗纹间距估计运动长度。

对于理想匀速直线运动模糊，运动长度与频谱零点间距近似成反比。程序根据检测到的暗纹间距计算长度估计值。

该过程属于启发式估计，可能受到图像纹理、噪声以及频谱高阶暗纹的影响。

### 2.3 运动 PSF 构造

根据估计得到的运动方向 θ 和长度 L，构造离散直线运动 PSF。

程序沿指定方向生成线段，通过插值方式将运动轨迹映射到离散像素网格，并归一化 PSF，使其元素之和为 1。

这里采用的是**空间不变的匀速直线运动模型**，不能完整描述真实拍摄过程中可能存在的曲线抖动、非匀速运动或空间变化模糊。

### 2.4 图像复原

使用估计的 PSF 进行频域复原，主要包括：

- **Wiener 滤波**：通过参数 K 控制反卷积与噪声放大之间的权衡。
- **CLS 滤波**：通过正则化约束缓解逆问题的病态性。

复原结果使用 PSNR 和 SSIM 评价，GT 仅用于实验结果评价及参数敏感性分析，不参与 Radon 运动参数估计。

## 4. 合成运动模糊实验

### 4.1 实验设计

从 DIV2K 选取一张清晰图像，使用已知的直线运动 PSF 生成合成模糊图像，再仅根据模糊图像估计运动方向和长度。

测试了 7 组运动参数，涵盖不同方向与长度。

合成模糊使用频域周期卷积生成，以便与后续频域复原采用一致的边界模型。

对每组图像，分别使用真实 PSF 和 Radon 估计 PSF 进行复原，以观察参数估计误差对复原效果的影响。

### 4.2 运动参数估计结果

| 真实方向 | 真实长度 | 估计方向 | 估计长度 |
|---:|---:|---:|---:|
| 0° | 23 px | 0° | 24.38 px |
| 30° | 23 px | 30° | 22.26 px |
| 60° | 23 px | 60° | 21.33 px |
| 90° | 23 px | 90° | 22.26 px |
| 30° | 12 px | 30° | 11.13 px |
| 30° | 40 px | 30° | 39.38 px |
| 30° | 60 px | 30° | 56.89 px |

7 组测试中：

- 运动方向均被正确估计，平均方向绝对误差为 0°。
- 运动长度平均绝对误差约为 1.30 px。
- 最大长度绝对误差约为 3.11 px，出现在 30°、60 px 这一组。

结果表明，在当前合成图像和所测试的参数范围内，频谱分析与 Radon 变换能够较准确地估计理想直线运动模糊参数。

需要注意，所有合成测试均基于同一张 DIV2K 原图，因此这些结果不能直接代表方法在不同图像内容上的泛化性能。

### 4.3 合成图像复原结果

下表给出使用估计 PSF 进行 Wiener 复原的结果，并使用真实 PSF 的 Wiener 结果作为参考。

| 真实方向与长度 | LQ PSNR | 估计 PSF + Wiener | 真实 PSF + Wiener |
|---|---:|---:|---:|
| 0°，23 px | 22.930 | 27.602 | 28.233 |
| 30°，23 px | 22.850 | 27.906 | 28.174 |
| 60°，23 px | 22.387 | 26.518 | 27.626 |
| 90°，23 px | 22.265 | 27.168 | 27.447 |
| 30°，12 px | 26.018 | 30.789 | 31.923 |
| 30°，40 px | 20.926 | 25.501 | 25.563 |
| 30°，60 px | 19.754 | 23.444 | 23.976 |

单位：dB。

可以观察到：

1. 在全部 7 组测试中，估计 PSF 的 Wiener 复原 PSNR 均高于模糊图像。
2. 使用真实 PSF 的复原结果总体优于使用估计 PSF 的结果，说明模糊参数估计误差会影响最终复原质量。
3. 对较长的运动模糊，参数估计和反卷积更加困难。CLS 对参数及核失配也比较敏感，例如 30°、60 px 的估计 PSF + CLS 结果低于原始 LQ。

因此，合成实验支持该方法在理想直线运动模糊条件下的有效性，但不能保证所有复原算法在全部参数下都取得改善。

## 5. RealBlur-J 真实模糊实验

### 5.1 运动 PSF 估计

对选取的 RealBlur-J 模糊图像进行频谱分析，得到：

- 估计运动方向：**29°**
- 估计运动长度：**26.95 px**

据此构造直线运动 PSF，并使用 Wiener、CLS 进行复原。

由于真实 PSF 未知，上述参数只能视为当前模型下的估计值，不能认定为真实相机运动参数。

### 5.2 Wiener 参数敏感性分析

固定估计的 Radon PSF，改变 Wiener 参数 K，得到以下结果：

| K | PSNR (dB) | SSIM |
|---:|---:|---:|
| 0.01 | 18.262 | 0.44308 |
| 0.03 | 19.755 | 0.55284 |
| 0.05 | 20.213 | 0.58477 |
| 0.10 | **20.333** | 0.60804 |
| 0.15 | 19.945 | **0.61173** |
| 0.20 | 19.364 | 0.61020 |
| 0.30 | 18.083 | 0.60187 |
| 0.50 | 15.932 | 0.57800 |
| 1.00 | 12.921 | 0.50988 |

原始 LQ 的 PSNR 为 18.925 dB，SSIM 为 0.57394。

当 K=0.01 时，复原结果出现明显振铃，PSNR 和 SSIM 均低于 LQ。随着 K 增大，复原质量先提高后下降。

在当前测试参数范围内：

- K=0.10 时 PSNR 最高，为 20.333 dB。
- K=0.15 时 SSIM 最高，为 0.61173。
- 相比 LQ，两项指标的最大提升分别约为 1.408 dB 和 0.03779。

这说明 Wiener 正则化参数对真实模糊复原效果有显著影响。过小的 K 容易放大失真和振铃，过大的 K 则会过度抑制复原结果。

## 6. 与 Task 2 高斯 PSF 的对比

### 6.1 对比设置

Task 2 在 RealBlur-J 分支中人为假设了四组高斯 PSF：

- Gaussian 15×15，σ=3
- Gaussian 35×35，σ=3
- Gaussian 35×35，σ=5
- Gaussian 35×35，σ=7

本实验将上述四组高斯 PSF 与 Radon 估计的运动 PSF 进行比较。

为了控制 Wiener 参数的影响，所有 PSF 均采用相同的 K 列表，并在固定 K=0.10 的条件下比较 PSNR 和 SSIM。

### 6.2 固定 K=0.10 的结果

| PSF 类型 | PSNR (dB) | SSIM |
|---|---:|---:|
| 原始 LQ | 18.925 | 0.57394 |
| Gaussian 15×15，σ=3 | 19.075 | 0.55628 |
| Gaussian 35×35，σ=3 | 19.073 | 0.55682 |
| Gaussian 35×35，σ=5 | 19.364 | 0.55538 |
| Gaussian 35×35，σ=7 | 19.525 | 0.54080 |
| **Radon Motion PSF** | **20.333** | **0.60804** |

在相同 Wiener K 下，Radon 运动 PSF 的 PSNR 和 SSIM 均高于四组高斯 PSF。

与 PSNR 最高的高斯配置（35×35，σ=7）相比，Radon 运动 PSF 的 PSNR 高约 0.808 dB。

相同 K 下，高斯配置的最高 SSIM 为 0.55682，Radon 运动 PSF 的 SSIM 为 0.60804，高约 0.05122。

### 6.3 结果分析

这表明，对于当前 RealBlur-J 测试图像，采用图像频谱估计的方向性运动 PSF，比直接使用所测试的四组高斯 PSF 更适合 Wiener 复原。

但该对比同时改变了 PSF 模型和参数来源：

- Task 2 使用人工指定参数的高斯模型。
- Radon 加分项使用从图像估计参数的直线运动模型。

因此，该结果能够说明 **Radon 运动 PSF 复原方案优于所测试的高斯 PSF 方案**，但不能将全部提升单独归因于 Radon 变换的参数估计精度。

此外，K 的选择利用了当前测试图像的 GT 指标，属于事后参数敏感性分析，不代表完全盲复原条件下的自动参数选择性能。

## 7. 实验局限性

本实验仍存在以下局限：

1. **运动模型简化**：采用空间不变的匀速直线运动 PSF，而 RealBlur-J 可能包含复杂相机运动及空间变化模糊。
2. **频谱估计依赖图像内容**：暗条纹检测可能受到纹理、噪声和高阶频谱暗纹干扰，长度估计不一定稳定。
3. **合成验证规模有限**：目前仅在一张 DIV2K 原图上测试了 7 组运动参数。
4. **真实图像测试有限**：目前只对一张 RealBlur-J 图像进行了完整的 Radon、参数敏感性和高斯 PSF 对照实验。
5. **复原质量仍不理想**：虽然真实图像的 PSNR、SSIM 得到改善，但仍然可能存在残余模糊、振铃及重影。
6. **参数选择依赖 GT**：K 搜索用于实验分析，尚未实现无需 GT 的自动正则化参数选择。

## 9. 实验结论

本实验实现了基于频谱分析与 Radon 变换的运动模糊 PSF 估计流程，并将估计的运动核用于 Wiener 和 CLS 图像复原。

在 7 组合成直线运动模糊实验中，运动方向均估计正确，长度平均绝对误差约为 1.30 px。使用估计 PSF 的 Wiener 复原结果在全部测试组合中均优于原始模糊图像。

在当前 RealBlur-J 图像上，Radon 估计得到约 29°、26.95 px 的运动 PSF。经 Wiener 参数调整后，复原结果达到 PSNR 20.333 dB、SSIM 0.60804。在固定 K=0.10 的对比中，两项指标均优于 Task 2 测试的四组人工假设高斯 PSF。

总体而言，实验验证了 Radon 变换辅助估计理想运动模糊参数的可行性，并表明基于图像估计的运动 PSF 可以改善当前真实模糊图像的复原指标。但对于复杂真实运动模糊，简单直线 PSF 仍存在模型失配问题，复原质量受到一定限制。
