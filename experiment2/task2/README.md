# Task 2：传统频域图像复原

## 1. 输入与实验设计

DIV2K 分支使用 [Task 1](../task1/content.md) 生成的六张 LQ 图像。两个高斯核为 15×15 和 19×19，均取 `σ=3`，各自搭配零填充（zero）、反射延拓（reflect）和周期延拓（wrap）。六组输入共享同一份标准差为 0.01 的高斯噪声。复原直接读取 Task 1 保存的 `psf_15x15.npy` 和 `psf_19x19.npy`，属于已知核的非盲复原。以 reflect 为例展示不同方法和参数的效果，同时计算三个边界条件的结果。

RealBlur-J 分支读取 Task 1 保存的真实模糊图和对应的清晰参考图。真实 PSF 未知，实验人工设定四个各向同性高斯候选核，再把每个候选核代入同一组非盲复原公式。控制尺寸或 `σ` 可检验这张图上高斯假设对结果的影响。GT 仅参与评价。

## 2. 复原方法与评价

将退化图与 PSF 变到频域。PSF 先补零到图像大小，再将原核中心移到数组索引 `(0, 0)` 以对齐 FFT 的卷积原点。记退化图频谱为 $G$，PSF 的频谱为 $H$。计算 $\widehat F$ 后用逆 FFT 得到复原图。

| 方法 | 频域公式 | 设置 |
|---|---|---|
| 全逆滤波 | $\widehat F=G/(H+\varepsilon)$ | $\varepsilon=10^{-3}$ |
| 受限逆滤波 | $D\le D_0$ 时 $\widehat F=G/(H+10^{-6})$，其余置零 | 每组扫描五个 $D_0$ |
| 维纳滤波 | $\widehat F=H^*G/(\lvert H\rvert^2+K)$ | 主实验 $K=0.01$ |
| 约束最小二乘（CLS） | $\widehat F=H^*G/(\lvert H\rvert^2+\gamma\lvert P\rvert^2)$ | 主实验 $\gamma=0.01$ |

$P$ 为拉普拉斯算子的频谱。受限逆滤波在未移位的 FFT 频谱上，以 `fftfreq(n) * n` 得到正负频率索引，$D$ 为索引到零频的欧氏距离，$D_0$ 的单位是频率索引格。小 $D_0$ 会丢弃较多细节，大 $D_0$ 会放行更多可能被逆滤波放大的噪声。维纳滤波使用常数 $K$ 近似噪声和信号的功率谱之比，CLS 用拉普拉斯惩罚约束高频能量。

全图 PSNR 和 SSIM 以归一化灰度 GT 为参考，取 `data_range=1.0`，复原图裁剪到 `[0, 1]` 后在浮点域计算。LQ 作为未处理基线。以下表格各单元格依次为 **PSNR（dB）/ SSIM**。

## 3. DIV2K 已知核复原

### 3.1 反射延拓主对比

| 方法 | 15×15，reflect | 19×19，reflect |
|---|---:|---:|
| LQ | 24.86 / 0.6433 | 24.78 / 0.6390 |
| 全逆滤波 | 5.16 / 0.0030 | 5.30 / 0.0039 |
| 受限逆 $D_0=30$ / $20$ | 19.49 / 0.3675 | 18.52 / 0.3518 |
| 受限逆 $D_0=60$ / $50$ | 21.60 / 0.4423 | 20.97 / 0.4139 |
| 受限逆 $D_0=100$ / $80$ | 23.62 / 0.5605 | 22.68 / 0.5008 |
| 受限逆 $D_0=150$ / $140$ | 25.24 / 0.6764 | 25.06 / 0.6608 |
| 受限逆 $D_0=200$ / $180$ | 22.21 / 0.6164 | 24.78 / 0.6893 |
| **Wiener** | **26.86 / 0.7788** | **26.86 / 0.7808** |
| CLS | 26.39 / 0.7720 | 26.42 / 0.7740 |

全逆滤波在 $\lvert H\rvert$ 很小的频段放大了噪声。15×15 受限逆在 $D_0=150$ 时两项指标最高，19×19 则分别在 $D_0=140$（PSNR）和 $D_0=180$（SSIM）取得最高值。两组主对比里，固定 $K=0.01$ 的维纳滤波使 PSNR 比 LQ 提高约 2 dB。

### 3.3 Wiener 和 CLS 参数扫描

固定 15×15 reflect 的输入和 PSF，每种方法分别扫描六档参数。

| $K$ | Wiener | $\gamma$ | CLS |
|---:|---:|---:|---:|
| 0.0001 | 15.05 / 0.1818 | 0.0001 | 18.04 / 0.3106 |
| 0.001 | 23.68 / 0.6399 | 0.001 | 23.21 / 0.6287 |
| 0.005 | 26.64 / 0.7729 | 0.005 | 25.79 / 0.7510 |
| **0.01** | **26.86 / 0.7788** | 0.01 | 26.39 / 0.7720 |
| 0.05 | 25.30 / 0.7394 | **0.05** | **26.83 / 0.7779** |
| 0.1 | 23.03 / 0.7034 | 0.1 | 26.76 / 0.7694 |

较小的参数会放大噪声，较大的参数会压低高频细节。在这六档参数中，Wiener 的两项指标均以 $K=0.01$ 为最高，CLS 均以 $\gamma=0.05$ 为最高。主对比保留固定的 $\gamma=0.01$，参数扫描刻画其调参空间。

## 4. RealBlur-J 未知核实验

以 15×15、35×35 两核比较固定 $\sigma=3$ 时的尺寸影响。以 35×35 核比较 $\sigma=3,5,7$。每个候选核均执行全逆、受限逆（$D_0=15,30,50,70,90$）、Wiener（$K=0.01$）和 CLS（$\gamma=0.01$）。

| 候选高斯核 | 全逆 | 受限逆 $D_0=30$ | Wiener | CLS |
|---|---:|---:|---:|---:|
| 15×15，$\sigma=3$ | 4.77 / 0.0027 | 18.79 / 0.5121 | 17.49 / 0.4463 | 16.33 / 0.3625 |
| 35×35，$\sigma=3$ | 5.37 / 0.0077 | 18.79 / 0.5112 | 17.44 / 0.4481 | 16.31 / 0.3669 |
| 35×35，$\sigma=5$ | 5.10 / 0.0101 | 18.64 / 0.4777 | 16.45 / 0.3999 | 12.43 / 0.1812 |
| 35×35，$\sigma=7$ | 4.77 / 0.0032 | 17.36 / 0.3855 | 16.50 / 0.4010 | 9.27 / 0.0996 |

LQ 为 **18.92 dB / 0.5739**。在本表的固定设置和完整 CSV 所列的受限逆范围内，四种高斯候选核得到的各项结果均低于 LQ。两组 $\sigma=3$ 的受限逆、Wiener 和 CLS 结果相近。固定 35×35 时，$\sigma$ 增大对 CLS 的影响更明显，Wiener 在 $\sigma=5$ 到 $7$ 间略有回升。这组实验说明在当前样本和参数下，用各向同性高斯核拟合真实模糊的效果有限。

## 5. 运行与产物

生成 Task 1 输出后，在 `experiment2/` 下运行。依赖 NumPy、OpenCV、SciPy、scikit-image、Matplotlib 和 pandas。

```bash
MPLBACKEND=Agg python3 task2/algorithm/code.py
MPLBACKEND=Agg python3 task2/param/param.py
MPLBACKEND=Agg python3 task2/realblur/realblur.py
```

`algorithm/picture_fixed/` 保存六组共 54 行指标和两组 reflect 的对比图。`param/param_fixed/` 保存 12 行参数指标、曲线和中心 256×256 局部图。`realblur/realblur_fixed/` 保存 LQ 基线、32 行复原结果和各组假设核的对比图。较早的输出保留在原目录，实验结果以这些 `*_fixed` 目录为准。旧版受限逆谱掩膜用非负索引构造半径，漏掉未移位频谱中的负频率。该项修正直接作用于受限逆滤波。
